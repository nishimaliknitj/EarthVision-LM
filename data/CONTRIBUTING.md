# Contributing to EarthVision-LM

Thank you for your interest in contributing to this systematic review repository.

## How to Contribute

### Reporting Missing Papers
If you know of an RS-MLLM paper published before 24 August 2026 that should have been included in Corpus A but was missed:
1. Open an **Issue** with the title: `[Missing Paper] <Paper Title>`
2. Include: arXiv ID or DOI, year, venue, why it meets inclusion criteria I1–I3
3. We will review and update the corpus in v1.1

### Reporting Errors in Data Files
If you spot an error in any CSV file (wrong benchmark score, wrong year, wrong venue):
1. Open an **Issue** with the title: `[Data Error] <file_name.csv> — <description>`
2. Provide the correct value and source

### Suggesting Improvements
For methodology suggestions or discussion of the hallucination taxonomy or design space:
1. Open a **Discussion** (GitHub Discussions tab)
2. Tag it appropriately: `methodology`, `taxonomy`, `benchmark`, `data`

## Pull Requests
- Fork the repository
- Create a branch: `git checkout -b fix/description`
- Make your changes with clear commit messages
- Submit a pull request with a description of what changed and why

## Code of Conduct
- Be respectful and professional in all interactions
- This is an academic repository; maintain scholarly standards
- No promotion of commercial products without disclosure
